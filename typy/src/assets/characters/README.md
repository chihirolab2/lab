# キャラクター個別画像

ここに画像を置くと、そのキャラクターは自動的にSVG仮イラストから画像表示に切り替わります（コード変更不要）。

## ファイル名

| ファイル名 | 用途 |
| --- | --- |
| `INFP.webp` | INFP ベースキャラクター（A/T・C/S 共通） |
| `INFP-TS.webp` | 任意。INFP の T·S だけ別画像にしたいとき（ベースより優先） |

拡張子は `.webp` / `.png` が使えます。ベースは `INTJ` `INTP` `ENTJ` `ENTP` `INFJ` `INFP` `ENFJ` `ENFP` `ISTJ` `ISFJ` `ESTJ` `ESFJ` `ISTP` `ISFP` `ESTP` `ESFP` の16種類です。

## 画像の条件

- **1人1ファイル**（1枚のシートをそのまま置かない）
- **背景透過**（図鑑カード・詳細・診断結果で背景色を重ねるため）
- バストアップ、縦長 4:5 目安、**1024×1280px以上**（詳細画面で大きく表示するため）
- **文字・色の点・枠などを含めない**（タイプ名や説明はアプリ側で表示します）
- 顔が画像の上寄りにあること（丸いアバターは上部を切り出して表示します）
